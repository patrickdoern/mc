Moonlight Commander

The two-pane file manager for macOS in the style of Norton Commander. Fast, fully keyboard-driven, free.

Download for macOS (DMG, approx. 4 MB)

Free and open source (MIT) · macOS 14 or later · Apple silicon · signed and notarized by Apple · 61 downloads so far

What the app can do

  • Two panels, full keyboard controlCopy, move, delete and rename with F5 to F8, masks like *.bak, selecting by pattern, quick search.
  • SFTP and FTP/FTPSOpen servers like local folders and copy files between your Mac and the server. SSH aliases and keys from ~/.ssh work, and passwords can be stored in the keychain.
  • A real terminalCtrl-O opens a shell in the active panel's folder, or an ssh session on the server for SFTP panels.
  • Viewer and editorSyntax highlighting, hex view, regex search, diff, Markdown and HTML preview.
  • Archives as folderszip, tar, 7z, rar, iso and more open with Enter like a directory.
  • Live updatesLocal panels reload automatically when the folder changes from outside.
  • Three color schemesNorton Blue, Dark and Light.
  • German and EnglishThe interface follows the system language and can be changed under Options → Configuration.

Essential keys

TabSwitch panel
F3 / F4View / Edit
F5 / F6Copy / Move
F7 / F8Create folder / Delete
⌘KConnect to an SFTP or FTP server
Ctrl-OShow or hide terminal
⌘DDirectory hotlist

The F-keys need "Use F1, F2, etc. keys as standard function keys" in the keyboard settings, or the Fn key. All functions are also available in the menu bar (F9).

Installation

Open the DMG and drag "Moonlight Commander" to "Applications". On first launch, macOS only asks whether you want to open an app downloaded from the internet.

Open source

Moonlight Commander is released under the MIT license. The source code is on GitHub, along with all versions as Releases.

About the version numbers: yes, 1.6.12 after just a few days is quite a sprint.

The app came out in November 2026. In the first days, I simply slept through bumping the patch version for small updates and raised the minor version every time instead. That took it from 1.0 to 1.6 within three days.

Since 1.6, I seem to be wide awake when it comes to version numbers too, and dutifully bump the patch version: 1.6.1, 1.6.2 …

So the high version number does not mean the app has decades under its belt. It is not quite there yet. That experience remains reserved for Norton Commander. 😉

Privacy

The app has no ads, no tracking and no accounts. It only checks for new versions with your consent (without personal data); otherwise connections are only made when you open a server yourself. Details in the privacy policy.
