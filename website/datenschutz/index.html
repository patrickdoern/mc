Die App

  • Die App läuft vollständig lokal auf deinem Mac. Es gibt kein Konto, keine Cloud, keine Analyse, keine Absturzberichte und keine Werbung. Sie prüft auch nicht von selbst auf Updates.
  • Netzwerkverbindungen entstehen nur, wenn du selbst über „Verbinden“ einen SFTP- oder FTP-Server öffnest. Sie gehen direkt an den Server, den du angegeben hast, nicht über mich.
  • Auf Wunsch speichert die App ein Server-Passwort im Schlüsselbund deines Macs. Es verlässt den Mac nur zur Anmeldung beim jeweiligen Server und lässt sich unter „Befehl → Gespeicherte Passwörter“ wieder löschen.
  • Einstellungen wie Ordner, Sortierung, Farbschema, Hotlist und die Chronik angesehener Dateien liegen lokal in den Einstellungen deines Benutzerkontos.

Diese Website

Die Website läuft auf einem eigenen Server. Sie verwendet keine Cookies, keine Analyse-Werkzeuge und lädt keine Inhalte von fremden Servern. Der Webserver führt keine Zugriffsprotokolle.

Damit die Seite ausgeliefert werden kann, verarbeitet der Server beim Aufruf technisch zwangsläufig deine IP-Adresse. Sie wird nicht gespeichert. Nur wenn ein technischer Fehler auftritt (etwa ein abgebrochener Verbindungsaufbau), kann sie in der Fehlermeldung des Servers stehen. Rechtsgrundlage ist das berechtigte Interesse an einem sicheren Betrieb der Website (Art. 6 Abs. 1 lit. f DSGVO).
