# Sicherheit / Security

## Deutsch

Sicherheitsprobleme bitte nicht öffentlich als Issue melden, sondern über „Report a vulnerability“ auf der Registerkarte [Security](https://github.com/patrickdoern/mc/security) des Repos (privat, nur für die Betreuer sichtbar). Alternativ erreichst du mich über die Angaben im [Impressum](https://moonlight-commander.org/impressum). Unterstützt wird jeweils die neueste Version, siehe [Releases](https://github.com/patrickdoern/mc/releases).

## English

Please do not report security problems as a public issue; use "Report a vulnerability" on the repository's [Security](https://github.com/patrickdoern/mc/security) tab (private, visible to the maintainers only). Alternatively, you can reach me via the details in the [legal notice](https://moonlight-commander.org/en/legal-notice/). The latest version is the supported one, see [Releases](https://github.com/patrickdoern/mc/releases).
